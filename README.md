# RoboRally

An object-oriented C++ implementation of the RoboRally board game.

## 🎮 Overview

RoboRally is a two-player board game where players navigate
robots across a 5×11 grid containing obstacles and special
game objects.

## ✨ Features

- Design Mode
- Play Mode
- Player movement commands
- Multiple game objects
- Turn ordering using antenna distance
- Health system
- Game object interactions
- Save/Load grid
- Copy/Cut/Paste objects
- Reboot & Repair
- Win condition

## 🧠 OOP Architecture

- Inheritance
- Polymorphism
- Virtual functions
- Encapsulation
- Separation of responsibilities
- Modular Action architecture
